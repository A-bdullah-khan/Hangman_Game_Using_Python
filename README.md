# Hangman_Game_Using_Python
A simple python based hangman game for guessing the correct word
FEATURES:
1) Selects a hidden word randomly from a predefined list
2) Display the word using dashes for unguessed letters
3) Allow the user to guess one letter at a time i-e only letters accepted and one letter at a time
4) Tracks corrcet and incorrect guesses
5) Limits the player to 6 tries
6) Displays all incorrectly guessed letters
7) Ends the game either when word is guessed or when user run out of tries.
